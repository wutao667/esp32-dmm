# CoreS3 直流电压电流表

使用 M5Stack CoreS3 的 Port B 连接 Unit INA226-1A。Grove 线提供 5 V 和 GND，I²C 使用 GPIO9（SDA）、GPIO8（SCL）和 7 位地址 `0x41`。

将被测直流电源接到模块的 INPUT 端子，负载接到 OUTPUT 端子，按板上的正负极标记接线。总线电压范围为 0–30 V DC。使用 10 Ω 分流电阻时，INA226 的电流测量满量程约为 ±8192 µA。

## 编译和烧录

在本目录用 PlatformIO 执行以下命令。

```powershell
pio run
pio device list
pio run -t upload --upload-port COM17
```

把 `COM17` 换成 CoreS3 的实际串口。屏幕上方以 V 显示总线电压，下方以 µA（屏幕标记 `uA`）显示带方向的电流，每 200 ms 刷新一次。正值对应从 INPUT 到 OUTPUT 的电流。断开 Grove 线时，读数变为 `--`，重新接上后会自动恢复。

INA226 对总线电压和分流电压分别采用 1.1 ms 转换时间及 16 次平均，每组标称耗时 35.2 ms，约 28.4 组/秒。固件在每组转换完成后读取并通过 USB 串口输出，可用 `pio device monitor --port COM17` 查看。屏幕每 200 ms 显示最新一组。

分流电压寄存器每计数代表 2.5 µV，除以 10 Ω 后，每计数对应 0.25 µA。

## Flash 记录

固件自动将每个 1 秒窗口内收到的电压和电流分别取平均，写入内部 LittleFS。无有效采样的窗口会跳过。右下角的 `REC` 是已写入 Flash 的条数，重启后会继续累加。

清除时点屏幕右上角的 `CLEAR`，再在 5 秒内点 `CONFIRM`。点击其他位置或等待超时可取消。清除成功后从下一个完整窗口恢复记录。空间不足时显示 `FLASH FULL`，已有记录保留。

侧面电源键也可以清除记录。短按一次进入确认，5 秒内再短按一次清除。两次操作可以混用电源键和触屏按钮。

日志文件为 `/meter-v1.bin`。每条 12 字节，小端序，依次是窗口开始时间（`uint32`，Unix UTC 秒）、平均电压（`float32`，V）、平均电流（`float32`，µA）。通过 USB 串口发送 `TIME <Unix UTC 秒>` 加换行可校准板载 RTC。RTC 未校准时，时间字段使用本次开机后的秒数。当前分区为空时，按 10% 空间预留估算可记录约 3 天。

## 网页曲线

CoreS3 连上已配置的 Wi-Fi 后，屏幕底部依次显示网络名称和路由器分配的 IP 地址。用能访问该地址的手机或电脑打开网页。网页分别显示 Flash 中的电压和电流曲线，默认每 4 秒刷新最近 900 条。可以切换每段条数、翻页查看历史，或轻触曲线查看单条记录。浏览器按本机时区显示 UTC 时间戳。

首次开机或清除 Wi-Fi 后，直接连接开放热点 `CoreS3-Setup`。手机或电脑通常会自动弹出配网页，也可手动打开 [192.168.4.1](http://192.168.4.1/)。点 **Configure WiFi**，选择 2.4 GHz 网络，填写该网络的密码并保存。连接成功后热点关闭，屏幕底部显示新的网页地址。配网参数保存在设备上，重启会自动连接。

长按侧面电源键触发 Wi-Fi 重置，设备重启并开启配网热点。USB 串口发送 `WIFI RESET` 加换行也可触发同一操作。Wi-Fi 重置保留 Flash 测量记录。短按两次仍用于清除测量记录。

「导出当前页 CSV」下载曲线当前显示的记录。「导出全部历史 CSV」下载点击时 Flash 中已保存的所有记录。CSV 四列依次为日期、时间、电流（µA）、电压（V）。已校时记录使用浏览器时区，未校时记录的日期留空，时间显示为开机后的时长。
