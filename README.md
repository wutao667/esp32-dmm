# ESP32 DMM电流计

用 M5Stack 小屏随时查看直流电流和电压。想知道设备什么时候开始耗电、待机电流有多大，或者一段时间内电流怎么变化，可以在手机上打开电流计网页，看曲线、看平均值，也可以导出数据。

## 能做什么

- **现场读数** — 小屏直接显示电流和电压。接上网络后，屏幕还会显示 Wi-Fi 名称和网页 IP。
- **记录变化** — 每秒保存一组平均电流和电压。断电重启后，已保存的历史仍可查看。
- **网页看曲线** — 电流曲线在前，电压曲线在后。页面上方显示最新值、历史平均和当前页平均。
- **导出 CSV** — 可导出当前页或全部历史，四列依次是日期、时间、电流和电压。
- **区分多台设备** — 屏幕、网页和配网热点都使用同一个四位设备编号。

## 两种机身

| 机型 | 屏幕怎么用 |
| --- | --- |
| **CoreS3** | 大屏同时显示电压和电流。可在屏幕上查看记录数、网络地址和清空确认。 |
| **AtomS3R** | 128 × 128 小屏以绿色大字显示电流，下方用蓝字显示电压，并列出日期时间、记录数和网络信息。 |

两款机型共用「ESP32 DMM电流计」网页，手机和电脑都可以查看。

## 电流档位

| 档位 | 对应的分流电阻 | 电流单位 |
| --- | ---: | --- |
| **8 mA**（默认） | 10 Ω | µA |
| **1 A** | 80 mΩ | mA |
| **10 A** | 5 mΩ | mA |

在网页左下角点「当前档位」，选择与实际分流电阻一致的一档，再点「确认」。设置会保存到设备上。

## 第一次使用

1. **接上测量模块。** CoreS3 使用 Port B，AtomS3R 使用 Grove 口。被测直流电源接到 INA226 模块的 `INPUT`，负载接到 `OUTPUT`，按模块标记接正负极。
2. **给电流计配网。** 手机连接屏幕上显示的免密码热点 `Esp32DMM-XXXX`。配网页没自动弹出时，打开 [192.168.4.1](http://192.168.4.1/)。点 **Configure WiFi**，选择 2.4 GHz 网络并保存。
3. **打开测量网页。** 手机或电脑连上同一网络，在浏览器输入电流计屏幕上显示的 IP。可轻触曲线查看某个时刻的读数，也可以翻看更早的记录。

## 按键怎么用

CoreS3 使用侧面的电源键，AtomS3R 使用屏下按键。

- **短按清零数据** — 短按一次，屏幕会提示确认。在 5 秒内再短按一次，清空测量历史并从零开始记录。
- **长按重新配置 Wi-Fi** — 长按按键进入配网模式，再连接屏幕上显示的 `Esp32DMM-XXXX` 热点。重新配网会保留测量历史。

## 管理测量历史

想留下数据时，点「导出全部历史 CSV」。记录空间用满后，设备会保留已有历史，实时读数继续更新。导出后，可点「清空历史」并再次确认，设备会开始新一轮记录。

## 远程固件升级

电流计连上 Wi-Fi 后，可以用同一网络里的手机或电脑升级。网页右下角显示当前版本，旁边就是「固件升级」。

1. 打开「固件升级」，选择与设备机型对应的固件文件。
2. 点「准备升级」，在设备上短按一次确认。
3. 点「上传并升级」，等待校验和自动重启。重新打开网页即可查看版本。

升级会保留 Wi-Fi 配置，测量历史从新一轮开始。需要保留旧记录时，可在升级前先导出 CSV。
